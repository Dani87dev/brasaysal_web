# Brasa y Sal

Concept website for a fictional grill restaurant, built as a portfolio project.

**Live:** https://brasaysal.rest

> Brasa y Sal is a fictional brand. The site is not affiliated with any real restaurant and is excluded from search engine indexing (`noindex`).

## Overview

Static, responsive website covering the full workflow of a small client project: naming and branding, visual design, content structure, development and deployment on a custom domain.

Development was carried out iteratively using Claude Code as an AI-assisted coding tool, with design direction, review and deployment handled manually.

## Tech stack

- HTML5, CSS3, vanilla JavaScript
- No frameworks, no build step
- Hosted on GitHub Pages
- Custom domain (Namecheap DNS) with HTTPS enforced

## Running locally

```bash
git clone https://github.com/dani87dev/<repo-name>.git
cd <repo-name>
```

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Deployed from the `main` branch root via GitHub Pages. The `CNAME` file maps the site to `brasaysal.rest`.
